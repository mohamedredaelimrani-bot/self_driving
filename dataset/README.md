# Dataset

Ce dossier contient les données utilisées pour l'entraînement et l'évaluation du modèle CNN.

## Contenu

- `driving_log.csv` : association entre les images et les valeurs de direction.
- `sample_images/` : exemples représentatifs des images du dataset.

Le jeu de données final contient **4 183 couples image-label**.

Les images complètes du dataset ne sont pas toutes publiées dans ce dépôt afin de limiter sa taille.
