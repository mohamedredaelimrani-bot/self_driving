# Scripts de préparation et d'entraînement

Ce dossier contient les scripts Python utilisés sur PC pour préparer les données,
entraîner le modèle CNN et évaluer le modèle final.

## Fichiers principaux

- `extract_frames.py` : extraction des images à partir des vidéos.
- `create_driving_log_v2.py` : génération des labels et création de `driving_log.csv`.
- `train_model.py` : entraînement du modèle CNN.
- `evaluate_best_model.py` : évaluation du modèle `best_model.h5`.
